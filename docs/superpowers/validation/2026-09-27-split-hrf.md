# Independent odd/even HRF parameter maps

> **Dated validation record:** Results and test counts apply to the recorded
> revision/settings, not necessarily this checkout. See the
> [documentation index](../../README.md) for current API and methods guidance.

The expanded NSD pipeline now saves an even-run HRF-index map and matching
odd/even parameter CIFTIs. Each parameter file contains response delay,
undershoot delay, response dispersion, undershoot dispersion,
response/undershoot ratio, onset delay, duration, and full-HRF peak time.
Values come directly from each half's selected library candidate.

Each half uses mean-stimulus leave-one-run-out prediction within its own runs.
Both halves require candidates to be estimable across the same run timing and
confounds, preserving the existing odd-to-even evaluation's eligibility rule.
Opposite-half BOLD and RT do not select the HRF. Both use the same 649-candidate
library and preserve the original grayordinate ordering. A half with fewer
than two runs has NaN maps and an explicit metadata reason.
